# Autoformalized conjectures

A static review site for the Lean 4 files an automated pipeline wrote for
open problems from Wikipedia's list of unsolved problems in mathematics and
the Kourovka Notebook, compiled against
[google-deepmind/formal-conjectures](https://github.com/google-deepmind/formal-conjectures).
Each page shows the source passage, the file split into its declarations, the
automated reviewer's notes, and how the file was produced.

## Data

`data/` is generated by the exporter in the
[autoformalization](https://github.com/epoch-research/autoformalization) repo
(`autoformalization/results_site/`) from one run's eval log and artifacts per
source (one Hawk eval set each), and committed as-is. It is Vite's public directory, so the site fetches exactly
these files (Lean is highlighted in the browser):

- `index.json` — the list (one row per file) and per-source metadata (areas,
  the run's outcomes and models, the notebook's TeX macros for KaTeX)
- `entries/<id>.json` — one file: byte-exact blocks with roles, claims and their
  source spans, definitions' justifications, checks, attempts (Kourovka entries
  also carry the statement's TeX as written; `statement` is its rendering)
- `alts/<id>.json` — every attempt (loaded on demand)
- `fc_status.json` — which entries Formal Conjectures has since gained a file for
- `overrides.json` — hand corrections (display titles, FC status)

## Local development

```sh
pnpm install
pnpm dev        # dev server on http://localhost:5173/
pnpm build      # check data, typecheck, bundle into dist/
pnpm preview    # serve dist/
```

Node ≥ 22.13 (`.tool-versions` pins one). Pushes to `main` deploy to GitHub
Pages through `.github/workflows/deploy-pages.yml`.
